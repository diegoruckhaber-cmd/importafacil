# Santa Catarina MVP implementation boundary

The SC layer is item-aware and conservative.

- TTD 409/410 eligibility is decided per item.
- TTD 77 remains a distinct conditional treatment.
- Import and subsequent output treatment are separated.
- Destinations such as commercial resale and industrialization are not treated as interchangeable.
- NCM-position changes after fractionation can block automatic benefit application.
- Valid concession and SC import entry are explicit inputs.
- Expense allocation and tax-base treatment remain separate decisions.

Current legal guardrails are informed by the SC SEF/COPAT 2026 consultations and must remain versioned as the regulation changes.
