# Combined MVP acceptance

The acceptance run must cover one multi-item import with:

- shared freight and insurance allocated to items;
- an operational expense allocated independently;
- different SC treatments per item;
- federal II, IPI, PIS-Importação and Cofins-Importação lines;
- 2026 PIS/Cofins rule behavior;
- explicit conditional warnings where legal eligibility is incomplete;
- final landed cost per item and operation total.

Passing this acceptance is necessary before the first hands-on test.
